## Important distinctions and remaining gaps

1. Smotion is an instruction/code package. Run Stester and HandRigOS are user-created instruction packages. Saving them does not execute them, install them into HAMZA, schedule jobs or deploy software.
2. Srig, Slens and Slout standalone definitions were not located in the accessible files inspected. Their use in conversation does not establish that their full packages were saved. They remain explicitly unarchived.
3. HAMZA_Source_Code.zip is the original Space source export (version 5), associated with the HAMZA Site project in its hosting metadata. It must not be silently treated as the CRB_NJR_26 GitHub tree. The existing GitHub d97b83e and Site v11 f0941a0 checkpoints recorded in the PRD are separate sources and require reconciliation before implementation.
4. No source code has been run or changed as part of this archival task. Functionality, production readiness, footage rights and all source claims have not been independently revalidated.
5. User-provided source ZIPs include their original project configuration. No credentials were introduced; do not publish these archives publicly or treat this preservation step as permission to connect services.
6. This folder and the existing Brain inherit the existing sharing. No new recipient or permission was added.

Original sources, extracted references, proposed implementation and measured test evidence must remain separately labeled.
